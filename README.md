# Luxor Connect

تطبيق اجتماعي سياحي تجريبي للأقصر مبني بـ HTML/CSS/JavaScript ويمكن تحويله إلى APK عبر GitHub Actions.

## الموجود حاليا
- منشورات نصية وصور من الهاتف.
- إعجاب وتعليقات ومشاركة.
- استكشاف أماكن سياحية.
- فعاليات.
- ملف شخصي.
- عبارات للسائح.
- مساعد سياحي مبدئي.
- لوحة إدارة محلية.
- تصدير واستيراد البيانات.
- بناء APK تلقائيا من GitHub.

## رمز الإدارة التجريبي
189132

> مهم: هذا الرمز موجود داخل JavaScript في نسخة التجربة، لذلك لا يعتبر حماية حقيقية. النسخة المتصلة بالإنترنت يجب أن تستخدم تسجيل دخول وقاعدة بيانات وصلاحيات على الخادم.

## تشغيل APK
ارفع المشروع إلى GitHub في مستودع جديد، ثم:
Actions → Build Android APK → Run workflow.
بعد نجاح البناء افتح نتيجة الـworkflow وحمّل Artifact باسم luxor-connect-apk.

## للنسخة الحقيقية متعددة المستخدمين
لتحويله إلى تطبيق اجتماعي فعلي مثل Facebook، نحتاج Backend وقاعدة بيانات وتخزين صور وحسابات مستخدمين وإشعارات وصلاحيات Admin. يمكن ربط المشروع بـSupabase أو Firebase في مرحلة ثانية.
