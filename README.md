# Mokaloke / Luxor Connect

تحديث تطويري متوافق مع هيكل المشروع المرفق، مع الحفاظ على صفحات المنشورات والفعاليات والملف الشخصي الموجودة.

## إضافات الواجهة
- صفحات الأصدقاء والبحث برقم الهاتف (واجهة أولية).
- محادثات خاصة ومجموعات محلية للتجربة.
- حالات نصية.
- لوحة ملصقات وإيموجي.
- ملف إعداد ربط Firebase وقواعد Firestore مبدئية.
- توسيع هيكل التطبيق دون استبدال المشروع الأصلي.

## مهم
الدردشة في هذا الإصدار تعمل محلياً على الجهاز فقط. لتشغيلها بين أجهزة مختلفة يجب إعداد Firebase Auth وFirestore وتقييد القواعد؛ راجع `FIREBASE_SETUP.md`. البحث الحقيقي برقم الهاتف يحتاج دليل مستخدمين وموافقة خصوصية وتحقق OTP. لا تعتبر قواعد Firestore التجريبية صالحة للإطلاق قبل مراجعتها.

## البناء
```bash
npm install
npx cap sync android
```
ثم ارفع التغييرات إلى فرع `main` ليعمل GitHub Actions.
